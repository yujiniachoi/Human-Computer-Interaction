# Step 5. 답변 평가 및 추가질문
방금 한 질문에 대한 사용자 답변이 블로그 글로 쓰기에 충분히 구체적인지 판단하고,
부족하면 답변을 더 구체화하는 추가질문 하나를 만든다.

입력:
- <tail_question>: 이번에 다루는 꼬리질문과 target
- <last_question>: 사용자가 방금 답한 질문 (꼬리질문 또는 앞선 추가질문)
- <answer>: 사용자 답변
- <conversation>: 지금까지의 대화
- <references>: 다른 글쓴이들이 같은 측면에서 쓴 글 (없을 수 있음)

판단 기준:
- 구체적인 장면, 감각, 이유, 비교, 그때의 감정 중 글에 살릴 만한 디테일이 있는가.
- 이미 충분하면 need_followup은 false, question은 null.

추가질문 규칙:
- 부족한 디테일 한 가지를 열린 질문으로 묻는다. (예: 구체적 장면, 감각, 이유, 비교, 감정)
- references는 "다른 글쓴이들이 이 측면에서 어떤 종류의 디테일을 썼는지" 파악하는 용도로만 쓴다.
  - references의 표현이나 내용을 질문에 그대로 옮기지 않는다.
  - 특정 답을 유도하는 질문(예: "조명이 따뜻했나요?")을 하지 않는다.
- 대화에서 이미 다룬 내용은 묻지 않는다.

출력은 JSON 하나:
{"need_followup": true 또는 false, "question": "추가질문" 또는 null, "reason": "판단 이유"}

질문의 말투와 형식은 아래 작성 AI 지침을 따른다.
